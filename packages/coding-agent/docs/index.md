# Dot Documentation

Dot is a terminal coding harness extended through TypeScript extensions, skills, prompt templates, themes, and packages.

## Quick start

```bash
npm install -g --ignore-scripts @dotkaio/dot
dot
```

Authenticate with `/login`, choose a model with `/model`, and start working. See [Quickstart](quickstart.md) for the full flow.

# Rebuild Plan (TypeScript)

This folder extracts the core backend/API integration patterns from the Android TV app so you can rebuild in TypeScript.

## Contents
- `architecture.md` — request architecture, session/auth model, app domains.
- `endpoints.md` — endpoint inventory with methods and where used.
- `auth-and-subscriptions.md` — login/autologin, verification, subscription/package handling.
- `typescript-blueprint.md` — suggested TS project structure and implementation strategy.

## Source of truth
All findings were extracted from `app/src/main/java/israel13/androidtv`.
